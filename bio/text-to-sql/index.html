Critic-Guided Retry Controller

The inference-time critic is a retry controller, separate from the GRPO/RLVR reward.

Generate SQL

↓
PASSreturn SQL
RETRYfailure-specific diagnostic
ABSTAINinsufficient / ambiguous request

RETRY returns to Generate SQL with diagnostic \(f_t\), bounded by \(K\). Clarification may be requested after ABSTAIN or after the retry budget is exhausted.

Failure-specific retry

Static-check failures return parser/schema/join diagnostics; execution failures return sandbox exceptions; semantic failures return critic evidence and one repair instruction.

Retry context

\[ f_t = (\mathrm{SQL}_{t-1},\ \mathrm{failure\ source},\ \mathrm{evidence},\ \mathrm{repair\ instruction}) \]

Schema separation

The semantic critic evaluates request–SQL–result consistency without schema access; the correction step retains schema context.
