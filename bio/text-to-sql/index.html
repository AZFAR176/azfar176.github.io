Critic feedback for Text-to-SQL retries

Inference circuit from EnterpriseSQL-RL. The critic is a retry controller, not a GRPO reward.

Retrieve schema
→
Generate SQL
→
Static checksparse · schema · join · safety
→
Executesandbox
→
Semantic criticrequest vs SQL vs result
↓ critic decision
Passreturn SQL
Abstainask to clarify
Retrysend diagnostic back
Retry feedback → previous SQL + failure source + evidence + one repair instruction
↑ re-enter from Generate  ·  bound by K

Static and execution failures also retry, but with their own diagnostics (parser/schema errors, or sandbox exceptions). The critic runs only after those checks succeed. It never sees the schema; correction still does.
