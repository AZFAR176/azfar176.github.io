I work on multimodal and language models, spanning visual grounding, RL-based post-training, agentic systems, and large-scale model training and inference.

My recent research studies how models can reason from relevant visual evidence, how this behaviour can be verified, and how verifiable feedback can be incorporated into post-training.

Current research interests

Research Philosophy

I am interested in building multimodal models whose decisions can be traced to relevant input evidence, and in using this connection to improve model training and reliability.

Current Research Direction

My work on smartphone-based clinical models led me to a broader question: can we verify not only whether a multimodal model is correct, but whether its decision actually depends on relevant visual evidence?

This motivates a progression from grounding and counterfactual verification toward verifiable multimodal post-training and active evidence acquisition.

Research flow: Visual Grounding → Counterfactual Verification → Verifiable Multimodal Post-Training → Active Evidence Acquisition

1. Execution-Grounded Text-to-SQL Agent

Implemented

How do I verify an agent's action?

Formulation

\[s_t=(q,\mathcal{S},h_t,e_t)\]
\[a_t \in \{\text{generate},\ \text{execute},\ \text{retry},\ \text{accept},\ \text{abstain}\}\]
\[ R_{\mathrm{raw}}(y)= \begin{cases} g_{\mathrm{exec}}, & R_{\mathrm{exec}}(y)=1\\[4pt] R_{\mathrm{ast}}(y)+R_{\mathrm{ngram}}(y), & \text{otherwise} \end{cases} \]

\(q\): query, \(\mathcal{S}\): schema, \(h_t\): trajectory history, \(e_t\): execution feedback. Execution is a pass grade (\(g_{\mathrm{exec}}=3\)); AST and SQL \(n\)-gram similarity apply only when execution fails, so structural fallback cannot outrank a correct program.

Agent loop

Query + Schema→ Generate→ Execute→ Verify
↑ Retry ←

Inference-time verification and training-time GRPO/RLVR rewards are related, but not identical.

2. Adaptive Agent & Tool Routing

Implemented

Which agent/tool should act?

Formulation

\[x_t=[\text{query},\ \text{task state},\ \text{history}]\]
\[a_t \in \mathcal{A}=\{\text{agent}_1,\ldots,\text{agent}_K,\ \text{tool}_1,\ldots,\text{tool}_M\}\]
\[r_t=\lambda_q Q_t-\lambda_l L_t-\lambda_r N_t^{\mathrm{retry}}\]
\[a_t=\arg\max_{a\in\mathcal{A}}\mathrm{UCB}(a\mid x_t)\]

Agent loop

Context→ Route→ Execute→ Quality / Latency / Retry
↑ Update ←

The router adapts agent/tool selection from online feedback rather than relying on fixed routing rules.

4. Evidence-Seeking Multimodal Agent

Research Direction

What should the agent do when evidence is insufficient?

Formulation

\[s_t=(I_t,q,h_t,G_t,c_t)\]

\(I_t\): current observation, \(q\): clinical context/question, \(h_t\): interaction history, \(G_t\): grounding information, \(c_t\): evidence confidence.

\[ a_t \in \{\text{zoom},\ \text{new-view},\ \text{ask},\ \text{retrieve},\ \text{predict},\ \text{abstain}\} \]
\[ R=R_{\mathrm{task}}+\lambda_g R_{\mathrm{ground}}+\lambda_a R_{\mathrm{acq}}-\lambda_c C(a) \]

Agent loop

Image + Context ↓ Ground + Reason ↓ Evidence sufficient?
Yes → Predict / Abstain
No → Acquire missing evidence → New observation → Re-ground

\(R_{\mathrm{task}}\) rewards decision correctness, \(R_{\mathrm{ground}}\) rewards dependence on relevant visual evidence, \(R_{\mathrm{acq}}\) rewards informative acquisition, and \(C(a)\) discourages unnecessary actions.
