2. Adaptive Agent & Tool Routing

Implemented

Which agent/tool should act?

Formulation

\[x_t=[\text{query},\ \text{task state},\ \text{history}]\]
\[a_t \in \mathcal{A}=\{\text{agent}_1,\ldots,\text{agent}_K,\ \text{tool}_1,\ldots,\text{tool}_M\}\]
\[r_t=\lambda_q Q_t-\lambda_l L_t-\lambda_r N_t^{\mathrm{retry}}\]
\[a_t=\arg\max_{a\in\mathcal{A}}\mathrm{UCB}(a\mid x_t)\]

Agent loop

Context→ Route→ Execute→ Quality / Latency / Retry
↑ Update ←

The router adapts agent/tool selection from online feedback rather than relying on fixed routing rules.
